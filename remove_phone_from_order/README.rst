This module removes phone numbers from address blocks in selected sales,
invoice, and delivery reports.

It adapts the contact widget used in reports so phone details are not
printed and adjusts the delivery address block on delivery slips.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Install the module.
2. Print a quotation, sale order, invoice, or delivery slip.
3. Verify that phone numbers are no longer shown in the report address
   blocks.
