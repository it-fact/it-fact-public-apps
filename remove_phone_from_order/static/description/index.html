Remove Phone from Order Reports

Clean up customer address blocks in sales, invoice, and delivery PDFs by hiding phone numbers where they should not be printed.

Cleaner PDFs

Phone details are removed from report address widgets.

Sales, invoices, delivery

Applies to quotation, order, invoice, and delivery report layouts.

Simple installation

No configuration is required after installing the module.

English

This module removes phone numbers from address blocks in selected sales, invoice, and delivery reports.

Usage

  1. Install the module.
  2. Print a quotation, sale order, invoice, or delivery slip.
  3. Verify that phone numbers are no longer shown in report address blocks.

Deutsch

Dieses Modul entfernt Telefonnummern aus Adressblöcken in ausgewählten Verkaufs-, Rechnungs- und Lieferberichten.

Verwendung

  1. Modul installieren.
  2. Angebot, Verkaufsauftrag, Rechnung oder Lieferschein drucken.
  3. Prüfen, dass Telefonnummern in den Adressblöcken nicht mehr angezeigt werden.

Technical Scope

  • Extends the report contact widget to suppress phone output.
  • Adjusts sale order, invoice, and delivery report templates.
  • Depends on sale, stock_delivery, and account.

Technischer Umfang

  • Erweitert das Kontakt-Widget in Berichten, um Telefonnummern zu unterdrücken.
  • Passt Angebots-, Rechnungs- und Lieferberichtsvorlagen an.
  • Benötigt sale, stock_delivery und account.
