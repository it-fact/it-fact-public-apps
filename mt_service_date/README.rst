Allows to set a date range where the service was provided.

If there is nothing set it expects the date to be equal to the invoice
date.

On product level there is also the possibility to only print the months
in which the service was provided. This is the minimum requirement for
austria and germany.

Key Benefits: The invoices are complient without ANY additional work if
invoice date = service date. With this module it's possible to have
multiple service dates per invoice (you bill for multiple months at
once.) The tool out of the box supports cut offs.

Adds the start and end field and prints it on the invoices.

For goods the delivery date is relevant. This module works only for
services but it works togehter with delivery dates. If there is a mix of
products it always puts it in the position lines.
